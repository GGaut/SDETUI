## Тест‑кейсы

### Тест‑кейс 1 – Проверка главной страницы

**Название**: Проверка наличия всех основных элементов главной страницы

**Предусловия**:

1. Запущен браузер.
2. Открыт URL `https://www.way2automation.com/`.

**Шаги**:

1. Дождаться полной загрузки страницы (ожидание появления элемента хедера).
2. Проверить, что отображается **Header** с контактной информацией (телефоны, Skype, e‑mail, соц‑сети).
3. Убедиться, что виден блок **Navigation**.
4. Нажать кнопку **Register Now** и убедиться, что открылась форма регистрации.
5. Прокрутить страницу до секции **Best Selenium Certification Course Online** и убедиться, что список курсов виден.
6. Прокрутить страницу до **Footer**, убедиться,что в футере присутсвует список контактов.

**Ожидаемый результат**:

- Хедер полностью отображается и содержит все перечисленные элементы.
- Блок навигации видим.
- Кнопка **Register Now** активна и открывает форму.
- Список курсов отображается под заголовком _Best Selenium Certification Course Online_.
- Футер содержит контакты

### Тест‑кейс 4 – Проверка формы авторизации

**Название**: Валидация полей входа, сообщения об ошибке и успешный вход

**Предусловия**:

1. Открыт URL `https://www.way2automation.com/angularjs-protractor/registeration/#/login`.

**Шаги**:

1. Убедиться, что отображаются поля **Username** и **Password**.
2. Проверить, что кнопка **Login** отключена.
3. Ввести неверные данные `invalid / invalid`. Нажать **Login**.
4. Считать появившееся сообщение об ошибке.
5. Очистить поля, ввести корректные данные `angular / password`. Нажать **Login**.
6. Проверить появившееся сообщение об успешной авторизации.

**Ожидаемый результат**:

- Поля присутствуют, кнопка **Login** недоступна до ввода данных.
- При неверных данных появляется сообщение **“Username or password is incorrect”**.
- При корректных данных появляется сообщение **“You're logged in!!”** и пользователь считается авторизованным.

### Тест‑кейс 5.1 – Sample Form

**Название**: Заполнение формы Sample Form и проверка сообщения об успешной регистрации.

**Предусловия**:

1. Открыт URL `https://www.way2automation.com/angularjs-protractor/banking/#/login`.
2. Пользователь находится на вкладке **Sample Form** (через кнопку _Sample Form_).

**Шаги**:

1. Ввести корректные данные в поля First Name, Last Name, Email, Password.
2. В разделе _Hobbies_ выбрать **Sports**.
3. В поле _About Yourself_ ввести строку «Самое длинное слово из предложенных хобби – N», где N – самое длинное слово из списка хобби (расчёт выполняется автоматически).

5. Считать появившееся сообщение.

**Ожидаемый результат**:

- Сообщение равно **“User registered successfully!”**.

### Тест‑кейс 5.2 – Bank Manager Login (добавление покупателя и открытие аккаунта)

**Название**: Добавление нового покупателя и открытие для него счёта

**Предусловия**:

1. Открыт URL `https://www.way2automation.com/angularjs-protractor/banking/#/login`.
2. Пользователь находится в режиме **Bank Manager Login** (через кнопку _Bank Manager Login_).

**Шаги**:

_Добавление покупателя_

1. Нажать **Add Customer**.
2. Заполнить форму First Name, Last Name, Post Code (использовать те же данные, что и в предыдущих шагах).
3. Нажать кнопку **Add Customer**.
4. Подтвердить появившееся alert‑сообщение **"Customer added successfully"**.

_Открытие аккаунта_ 5. Нажать **Open Account**. 6. В выпадающем списке **Customer** выбрать созданного покупателя. 7. В выпадающем списке **Currency** выбрать любую валюту (например, Dollar). 8. Нажать кнопку **Process** и подтвердить alert‑сообщение **"Account created successfully"**.

**Ожидаемый результат**:

- После добавления покупателя появляется alert с текстом **“Customer added successfully”**.
- После открытия аккаунта появляется alert с текстом **“Account created successfully”**.

### Тест‑кейс 5.3 – Customer Login (депозит, вывод, проверка баланса, очистка истории)

**Название**: Вход как клиент, операции депозита/вывода, проверка баланса, очистка истории и снятие оставшихся средств

**Предусловия**:

1. Открыт URL `https://www.way2automation.com/angularjs-protractor/banking/#/login`.
2. Существует клиент, созданный в тест‑кейсе 5.2.

**Шаги**:

1. Перейти в раздел **Customer Login**.
2. Выбрать клиента в выпадающем списке и нажать **Login**.
3. Убедиться, что отображается приветствие `Welcome firstName lastName !!`.
4. **Депозит** – ввести сумму `100321`, подтвердить сообщение **“Deposit Successful”**, проверить, что запись присутствует в **Transactions**.
5. **Неуспешный депозит** – ввести `0`, подтвердить, проверить, что сообщение **“Deposit Successful”** НЕ появляется, запись `0` отсутствует.
6. **Снятие** – считать текущий баланс, ввести случайную сумму `N` (1 <= N <= баланс), подтвердить сообщение **“Transaction successful”**, проверить наличие записи в **Transactions**.
7. **Неуспешное снятие** – попытаться снять `1000000`, проверить наличие сообщения **“Transaction Failed. You can not withdraw amount more than the balance.”**, убедиться,что запись `1000000` отсутствует.
8. **Проверка баланса** – сравнить баланс, отображаемый на странице, с суммой, подсчитанной из таблицы **Transactions**.
9. **Снятие всех оставшихся средств** – нажать **Withdrawn**, ввести текущий остаток, подтвердить сообщение **“Transaction successful”**, баланс становится `0`.
10. **Очистка истории** – открыть **Transactions**, нажать **Reset**, нажать **Back** таблица пустая, баланс остаётся `0`.

**Ожидаемый результат**:

- Все сообщения соответствуют описанным выше.
- Таблица **Transactions** отображает только те операции, которые действительно были проведены.
- После шагов 9‑10 баланс равен `0`, а история транзакций полностью очищена.

### Тест‑кейс 5.4 – Delete Customer

**Название**: Удаление ранее созданного клиента из списка покупателей

**Предусловия**:

1. Открыт URL `https://www.way2automation.com/angularjs-protractor/banking/#/login`.
2. Существует клиент, созданный в тест‑кейсе 5.2.

**Шаги**:

1. Перейти в режим **Bank Manager Login**.
2. Нажать кнопку **Customers**.
3. В поле поиска ввести `firstName`.
4. Убедиться, что клиент найден в таблице.
5. Нажать кнопку **Delete** рядом с найденной записью, подтвердить alert.
6. Очистить поле поиска и повторно выполнить поиск `firstName`.

**Ожидаемый результат**:

- После подтверждения клиент больше не появляется в результатах поиска; таблица не содержит запись с данным именем.
